# AI Team Architect Agent

Agent version of the `ai-agents` library template: a bot that runs its workflows on a schedule.

1. Replace `{{BOT_NAME}}` in `system-prompt.md` and `workflows/getting-started/SKILL.md`.
2. Paste `system-prompt.md` as the bot instructions.
3. Import `workflows/getting-started` from here plus all workflows in `../../library/ai-agents/workflows/`.
4. Keep `capabilities.md` as reference for schedules.
